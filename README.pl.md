**Krótki Opis Projektu** <br>
Responsywna strona osobista stworzona w ramach projektu zaliczeniowego podczas **III** roku studiów na przedmiot **Aplikacje Internetowe**. <br>
Strona prezentuje **moje zainteresowania** oraz **projekt gry komputerowej**.

## 🛠️ Technologie

- **HTML5** — semantyczna struktura strony i formularze.
- **CSS3** — wygląd, responsywność oraz przejścia.
- **JavaScript** — interakcje i zapamiętywanie ustawień.
- **GitHub Pages** — hosting statycznej strony.
- **Web3Forms** — zewnętrzna usługa przekazująca zgłoszenia z formularza na skonfigurowany adres e-mail.

## 🔌 Uruchomienie lokalne

1. Pobierz repozytorium jako **ZIP** i rozpakuj.
2. Otwórz folder projektu w **Visual Studio Code**.
3. Kliknij prawym przyciskiem **główny plik `index.html`** i wybierz **Open with Live Server**.

Możesz również otworzyć główny `index.html` bezpośrednio w przeglądarce.
