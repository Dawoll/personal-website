My game

My video game

I have always dreamed of creating my own video game. I am now learning to develop a project in my free time. As this is my first game, progress is gradual. The planned genre is a Top-down 2D roguelike.

I am trying to create the first sprites and animations myself in Aseprite, even though it can be challenging and time-consuming.

The engine I use is Unity. The code is written in C# using Visual Studio.

I store and update the project code in a private GitHub repository.

Current project status

The project is only a few weeks old and is still at a very early stage, so there is not much to show yet.

A brief list of current features:

  • Player
    • Character sprite and animations
    • Input handling
    • Movement around the map
    • Basic statistics
    • Spawning the character from a prefab and adding it to the player list
  • Enemies
    • Placeholder character sprite and animations
    • Basic movement around the map without advanced rules
    • Chasing the player
  • Procedural room generation script
    • Creating tile sprites
    • Setting their sizes and assigning pivots
    • Choosing room sizes from a list
    • Randomly placing room doors
    • Fitting floors, walls and doors to the generated room size
  • Items
    • Creating a file containing basic item data
    • Creating item assets using ScriptableObjects
    • Creating an item prefab
    • Spawning items in the scene
    • Detecting the player near an item
    • Displaying a pickup prompt
    • Handling item pickups
    • Removing items from the scene
  • Inventory
    • Initial inventory interface created in Unity's UI Builder
    • Preparing inventory management scripts

I have spent the most time on procedural map generation, which currently creates empty rooms. Learning how to work with differently sized 2D objects and fit the tiles together took considerable time.

The script does not use predefined room templates. Instead, it takes room dimensions and places the tiles accordingly, producing a unique map layout, one of the characteristic features of the roguelike genre.

I use separate tiles for floors, doors, main walls, side walls and corners. Almost every element has a different size, and its variants also differ in orientation. For example, corners come in eight variants: four inner and four outer corners, corresponding to different rotations.

  • Example tile sizes
    • Floor, doors, main walls - 6×6
    • Side walls - 1×6
    • Corners - 1×1

The idea behind this generator seems simple, but implementing it turned out to be quite complex.

The code needs to account for many offsets caused by different tile sizes. The generator can create maps containing up to 100 rooms.

The next step is to add branching paths, allowing one room to connect to several others. Currently, the rooms form one long, unnatural chain.

I am currently working on combat, health and a player inventory for storing items picked up in the scene.
