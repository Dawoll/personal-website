**Brief Project Description**
A responsive personal website created as a course project during my third year of study for **Internet Applications**. <br>
The website presents my interests and my game project.

## 🛠️ Technologies

- **HTML5** — semantic page structure and forms.
- **CSS3** — styling, responsive layouts and transitions.
- **JavaScript** — interactions and saved preferences.
- **GitHub Pages** — static website hosting.
- **Web3Forms** — an external service that forwards form submissions to the configured email address.

## 🔌 Run locally

1. Download the repository as a **ZIP** and extract it.
2. Open the project folder in **Visual Studio Code**.
3. Right-click the **root `index.html` file** and select **Open with Live Server**.

You can also open the root `index.html` directly in your browser.
